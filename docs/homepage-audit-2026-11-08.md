## Подтверждённые проблемы и исправления

1. Синхронные многопроходные расчёты шума для четырёх текстур heavenly.js блокировали загрузку. Существующие формы облаков и планета экспортированы в WebP; их движение по-прежнему рисуется прежним Canvas. Сохранены лимит кадров, DPR и остановка вне экрана. Генерация облаков основателей не возвращалась.
2. Lighthouse обнаружил блокирующий внешний CSS Google Fonts. Те же Cormorant Garamond и Manrope теперь локальные WOFF2, с исходными языковыми диапазонами и OFL-лицензиями. Убрана неиспользовавшаяся DM Sans. Два основных serif-поднабора предзагружаются.
3. Слишком большой PNG Нэнси получил адаптивные WebP-копии. Исходник и внешность не менялись, PNG остаётся fallback. Главная корона сохраняет fetchpriority=high, без lazy loading. Остальные нижние изображения продолжают загружаться лениво.
4. Ореол короны, сапфиры, жемчуг и искры меняли filter в keyframes. Размытие/свечение стали постоянными, а интенсивность и движение меняются через opacity/transform. Сами эффекты не выключены.
5. Убран большой blur фона «О служении» и размытие большого декоративного слоя анонса; мягкость сохранена радиальными градиентами. Фон about теперь останавливается вне экрана/в скрытой вкладке. Три сцены используют общий IntersectionObserver и один visibilitychange вместо отдельных слушателей.
6. Заголовок первого экрана больше не анимирует letter-spacing, вызывающий перерасчёт макета. Тексты с совпадающим переводом не пересоздаются при инициализации. Высота документа для индикатора прокрутки обновляется ResizeObserver при смене языка и раскрытии деталей.
7. «О служении» по умолчанию видим без JavaScript; анимация применяется как улучшение. Исправлено случайное переопределение фона между героем и about. Отличительные композиции секций и намеренно контрастный раздел контактов сохранены.
8. Золотые крупные акценты используют #A47C39, мелкие золотые ссылки — более тёмный тон для контраста. Футер стал контрастнее; его подпись немного увеличена. Исправлены несовпадающие доступные названия логотипа и переключателя языка, найденные Lighthouse.
9. Для главной собраны homepage.min.css и homepage.min.js: один CSS и один defer JS вместо четырёх запросов каждого вида. Исходники сохранены; другие HTML-страницы продолжают использовать обычные общие исходники. Cloudflare не требует Node.js при публикации — готовые файлы включены в Git.

## Методика

Изолированный headless Chrome, локальный HTTP-сервер, одинаковые условия до/после. Lighthouse 13.6.0, штатные mobile/desktop профили с Lighthouse throttling; это лабораторная симуляция, а не показатели Cloudflare/реального iPhone. Версия браузера: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) HeadlessChrome/153.0.0.0 Safari/537.36.

Отдельный CDP-тест: ширины 390 и 1440, DPR 1, без ограничения CPU/сети, ожидание шрифтов, 5 секунд первого экрана и 5 секунд ускоренной прокрутки всей страницы. rAF на этом компьютере работает около 240 вызовов/с; это **не** частота реально представленных GPU-кадров и не обещание 240 FPS посетителям. Снимки и замеры проводились отдельными фазами.

Реальные полевые Core Web Vitals/CrUX и INP недоступны; программные клики и TBT не выдаются за реальный INP. Safari и настоящий iPhone не тестировались. Полная память браузера, видеопамять, температура и энергопотребление не измерялись.

Один промежуточный desktop Lighthouse завис, его собственный процесс и дочерние процессы были остановлены. После исправлений оба финальных прогона завершились успешно. В таблицах финальные результаты, без выбора лучшего из серии. Колебания отдельных метрик при повторном запуске ожидаемы.

После изменения CSS/JS-исходников главной **нужно пересобрать готовые файлы**, иначе главная продолжит использовать предыдущую сборку. При наличии Node 24+ из корня проекта:

```powershell
npm install --prefix output/audit-tools/build --no-audit --no-fund --ignore-scripts clean-css terser
node tools/build-homepage.mjs
npm install --prefix output/audit-tools/lighthouse --no-audit --no-fund --ignore-scripts lighthouse
node tools/audit-homepage.mjs after --lighthouse
```

Raw JSON, HTML Lighthouse-отчёты и полные снимки главной 390/1440 находятся локально в output/homepage-audit/before и after. Они не включены в публикацию вместе с временными Node.js/npm пакетами. Статические артефакты собираются заранее; сервер сайта и база данных не добавлены.
