# Публичные продажи Tribute Digital Products

Владелец открывает **Продажи и доступы → Tribute → Публичные продажи**.
Переключение требует подтверждения, записывается в D1 вместе с временем,
проверенным Cloudflare Access ID владельца и историей операции. Только владелец
может изменить режим. После внедрения он выключен; никаких новых переменных
Cloudflare или ключей не требуется.

При включении продаются опубликованные платные видео с активным сопоставлением
Digital Products, готовым видеоисточником, совпадающей ценой RUB и одобренным
официальным товаром. Цена и срок берутся из существующего сопоставления.
Активность сопоставления и публикация видео определяют отдельные предложения;
настройка Shop «Продажа включена» не включает Digital Products.

Покупатель проходит существующий вход и подтверждённую привязку Telegram.
Сервер повторно проверяет товар и режим перед возвратом официальной ссылки
Tribute. Параметры браузера не подтверждают оплату: доступ выдаётся только после
проверенного webhook с Telegram ID покупателя, уникальным purchase_id и точной
ценой/валютой. Неопознанные покупки сохраняются для ручного разбора.

**Отключить публичные продажи** блокирует новые переходы через сайт, включая
прямые API-запросы. Каталог, бесплатные видео и оплаченные доступы сохраняются.
Уже открытая страница Tribute или ранее полученная внешняя ссылка может принять
платёж: переключатель сайта не отзывает ссылку у платёжного сервиса. Такие
подписанные покупки после первого включения продолжают обрабатываться при паузе.
Метка первого запуска не стирается. Невалидные уведомления, дубликаты и покупки
без подтверждённой привязки не получают доступ; возврат отзывает только право
соответствующего заказа. Сроки ранее выданных прав при переключении не меняются.

Тестовый режим одного участника работает до первого публичного включения. После
первого включения общая пауза также закрывает этот путь начала новой оплаты.
Кнопка «Выключить тестовую выдачу» относится только к прежнему тестовому режиму,
а не к исполнению уже оплаченных публичных покупок.

Отдельные переменные Shop SALES_PUBLIC_ENABLED/TRIBUTE_PAYMENTS_ENABLED и его
webhook не включаются этим переключателем. Аварийные серверные ограничения
SALES_ENABLED/MEDIA_PAID_ENABLED/TRIBUTE_DIGITAL_ENABLED сохраняются. Для Digital
новый переключатель D1 заменяет необходимость менять TRIBUTE_DIGITAL_LIVE_ENABLED
при каждом запуске/паузе. Секрет TRIBUTE_API_KEY остаётся только на сервере.

Миграция 0015 создаёт одну новую таблицу digital_public_sales с выключенным
состоянием. Существующие пользователи, настройки теста, заказы, платежи, права,
сопоставления и курсы валют не изменяются.
