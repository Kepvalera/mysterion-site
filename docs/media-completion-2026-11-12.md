# Завершение четырёх задач медиатеки и продаж

Изменения поверх Production 1382333. Полный аудит и миграции не выполняются.

1. Владелец может удалить пустой курс/поток без связей. Любые уроки, заказы или
   ранее выданные разрешения переводят удаление в архивирование. Подтверждение
   и ревизия обязательны; проверка связей и изменение атомарны. История, уроки,
   материалы и права сохраняются. Архив скрыт из публичного каталога, но остаётся
   в кабинете обладателя действующего разрешения, включая уроки и просмотр.
   Восстановление публикует курс, не включает продажу автоматически. Номера
   потоков 3–6 не меняются; реестр номеров не удаляется. DE сохраняется.
2. Общий поиск имени, фамилии и email добавлен в выбор участника для ручной
   выдачи: ввод запускает поиск с задержкой 250 мс, устаревшие ответы игнорируются,
   пустой результат объясняется. Выбор обязателен. Старый рабочий поиск раздела
   «Участники» не изменялся. Серверные действия выдачи/продления/отзыва и текущий
   вид отозванных разрешений сохранены.
3. Цена администратора показывается в карточках и окнах просмотра обеих
   публичных медиатек. Бесплатные записи не становятся платными. Кнопка покупки
   требует включённой продажи, положительной цены, актуальных условий, готового
   материала, включённого автоматического способа и активного RUB-магазина.
   Для действующего личного доступа покупка скрыта. Отказ проверки метода оплаты
   скрывает кнопку. Используется существующий GET /shops только при уже
   включённых автоматических платежах; в Production они остаются выключенными.
   Ручное оформление видео не представляется работающей автоматической оплатой.
4. Платные YouTube-записи разрешены через существующее редактирование видео.
   Предупреждение объясняет возможность передачи ссылки и более слабую защиту.
   YouTube ID выдаётся существующим endpoint просмотра лишь после проверки
   конкретного видео/курса, срока и отзыва разрешения. В публичных каталогах ID
   и ссылка не возвращаются. Неавторизованный доступ — 401, без разрешения — 403.
   Bunny остаётся основным защищённым хостингом; его настройки и привязка уже
   загруженных Bunny-файлов не меняются. Для них сохраняется прежний запрет
   случайной замены привязанного источника. YouTube не является абсолютной
   защитой: полученную разрешённым зрителем ссылку можно передать другим.

Не менялись исправленный `media-player.js` из 1382333, функции авторизации,
письма, сессии, параметры и код интеграции Tribute, реальные заказы/права.
Цена в модальном окне добавлена внешним адаптером к существующему плееру.
Использованы существующие колонки и состояния, новые таблицы не нужны.

Точечные проверки:

```text
node --import ./tools/register-viewer-wasm.mjs tools/test-media-completion.mjs
node --import ./tools/register-viewer-wasm.mjs tools/test-media-completion-browser.mjs
node tools/test-media-completion-runtime.mjs
```

Также проверяются существующие тесты платформы, ручных продаж, интерфейса
продаж и бесплатных источников, а также регрессия исправления 1382333.
Все тестовые аккаунты/материалы/операции — локальные, реальные платежи и письма
не создаются. В Production проверяются только чтение, запрет доступа без
сессии, отсутствие YouTube ID в открытых API и сохранность данных/флагов.
