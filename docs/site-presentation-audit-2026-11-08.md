# Визуальный и технический аудит MYSTERION INTERNATIONAL

Дата: 8 ноября 2026. Исходная версия Git: c14a3b7. Изменения этого аудита подготовлены локально; commit, push и изменение настроек production не выполнялись.

## Вывод

Основная визуальная композиция уже цельная: первый экран с короной, светлый редакционный блок о служении, основатели, контрастный анонс школы, асимметричные фотографии конференций и текстовая медиа-навигация. Полная перестройка не нужна. Новые эффекты добавлены в существующие компоненты, фотографии и тексты сохранены.

Сайт нельзя считать полностью подключённой видеоплатформой: опубликованный `/api/media/videos` возвращает **503 not_configured**. Сам `/media` открывается, но показывает подготовительное состояние. Это отдельная задача конфигурации Cloudflare/D1/Access; аудит не менял bindings, роли, секреты или MEDIA_PAID_ENABLED.

## Что проверено на опубликованном сайте

- Главная отвечает HTTP 200.
- Школа, фотографии, оба архива, проповеди и медиатека после штатного Cloudflare redirect `.html` → адрес без расширения отвечают HTTP 200. HTTP 308 на исходном адресе не является потерянной страницей.
- `homepage.min.css` и `homepage.min.js` отвечают HTTP 200, передаются с Brotli-сжатием.
- Состояние медиакаталога проверено только публичным GET. Авторизованные кабинеты и реальные права просмотра в этом аудите не тестировались и не изменялись.

## Найдено и исправлено

1. Часть старых CSS-селекторов появления не соответствует новым редакционным компонентам. В существующем `home.js` расширен уже имеющийся IntersectionObserver: направления, строки медиа, цитата, FAQ и две колонки контактов получили плавное однократное появление. По умолчанию контент видим. Задержка в группе ограничена 150 мс; никаких пустых блоков ожидания.
2. Направления получили раскрытие тонких золотых линий, смену цвета заголовка и небольшой сдвиг стрелки при наведении на компьютере. Доступен видимый клавиатурный фокус. Новых карточек, фотографий и разделов нет.
3. У цитаты мягко меняется сияние декоративной звезды. В контактах медленно перемещается золотисто-голубое освещение. Используются transform/opacity, без нового Canvas, библиотек и больших blur-фильтров. Две сцены добавлены в общий контроллер видимости: эффекты останавливаются вне экрана и в скрытой вкладке.
4. Мобильный фон первого экрана ранее рисовался примерно с настольной частотой. Для медленных облаков и звёзд установлен лимит 30 отрисовок/с на ширине менее 641 px. CSS-анимации короны и драгоценностей сохранены. В проверке измерено около **29,65 отрисовки Canvas/с**; это не измерение FPS дисплея.
5. Начальное уведомление ResizeObserver могло повторять явную инициализацию Canvas и пересоздавать ту же поверхность. Добавлена проверка размеров и DPR перед перераспределением Canvas.
6. Портрет основателей ниже первого экрана переведён на native lazy loading и низкий приоритет. Изображение короны сохраняет fetchpriority=high и загрузку без lazy. Файлы людей, пропорции, лица и композиция не менялись.
7. Убраны постоянные will-change у одноразовых декоративных появлений/линии. Новые появления не сохраняют transform после окончания анимации. Все постоянные эффекты учитывают prefers-reduced-motion.
8. Шесть ссылок направлений теперь связаны с заголовками через aria-labelledby: названия автоматически соответствуют RU/EN/DE. Добавлены переводы доступных названий короны, навигации и основных ценностей.
9. Пересобраны обе готовые версии homepage.min.css/js из исходников. Другие страницы продолжают использовать свои прежние CSS/JS.

## Lighthouse: до и после

Lighthouse 13.6, локальный HTTP, headless Chrome на этом компьютере, стандартные мобильный и настольный профили. Одинаковый способ запуска через существующий Chrome debugging port. Это одиночные лабораторные прогоны, не полевые Core Web Vitals и не замер настоящего iPhone.

| Профиль | Performance | FCP | LCP | TBT | CLS | Accessibility |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Mobile до | 74 | 1,55 с | 5,11 с | 299 мс | 0 | 100 |
| Mobile после | 80 | 1,66 с | 4,44 с | 233 мс | 0 | 100 |
| Desktop до | 99 | 0,44 с | 1,02 с | 13 мс | 0 | 100 |
| Desktop после | 99 | 0,45 с | 0,87 с | 21 мс | 0 | 100 |

Best Practices и SEO — 100 в обоих профилях до/после. Мобильные LCP и TBT улучшились в этом сравнении; FCP немного вырос. Настольный TBT вырос на 8 мс. Отдельные колебания при повторном запуске ожидаемы. Мобильный LCP 4,44 с всё ещё требует внимания, поэтому «идеальная скорость» не заявляется. Влияние каждой отдельной правки не изолировалось.

Первый запуск Lighthouse обычным CLI завис и был остановлен по таймауту. Для таблицы использованы завершившиеся прогоны через отдельно запущенный Chrome; незавершённому запуску не присваивался результат.

## Прокрутка и память

Отдельный CDP-тест — локальный Chrome, DPR 1, без ограничения сети/CPU. Интервалы requestAnimationFrame показывают ритм вызовов, а не частоту реально представленных GPU-кадров.

| Ширина | Интервалы >50 мс при ускоренной прокрутке, до → после | Максимальный интервал, до → после |
| --- | ---: | ---: |
| 390 | 3 → 3 | 116,5 → 83,4 мс |
| 1440 | 0 → 0 | 25,1 → 29,2 мс |

В прогретой сцене первого экрана интервалов >50 мс не зарегистрировано. При быстрой мобильной прокрутке три задержки остались; отсутствие любых рывков не заявляется. В этих фазах синхронных Long Tasks не зарегистрировано.

Минутная повторная прокрутка с принудительным GC: heap 924632 → 934684 → 934852 → 934852 байт, DOM — 993 узла, слушатели — 31 во всех точках. После прогрева роста не обнаружено; это не доказательство отсутствия многочасовых утечек или перегрева телефона.

Сырой homepage-аудит отмечает один незагруженный lazy-рисунок: средний облачный слой, скрытый CSS на телефоне. Оба видимых слоя загружаются и движутся; сетевой ошибки для скрытого слоя нет.
