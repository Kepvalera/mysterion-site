# Проверка MYSTERION MEDIA — кабинеты и коллекции

Дата: 8 ноября 2026. Это результаты локальной проверки кода, не проверка production-инфраструктуры.

## Выполнено

- `tools/test-media.mjs`: **166 проверок**, SQLite in-memory с реальными RSA-подписями JWT и изолированным Bunny mock. Проверены сохранность старой схемы, CRUD, роли/audiences, Origin, обходы доменов и закрытые HTML-шаблоны, привязка существующего Bunny-видео, ручной доступ без создания покупки, отзыв/истечение/блокировка, коллекции/скрытие/фильтрация и двоичная обложка D1.
- `tools/test-bunny-upload.mjs`: **5 сценариев** TUS, куски 8 МиБ, пауза/возобновление с HEAD, обновление истёкшей подписи, запрет стороннего Location. Реальных загрузок нет.
- `tools/check-media-browser.mjs`: **67 проверок** существующей медиатеки/редактора/загрузки/плеера и закрытой конфигурации в Chrome. Проверочная загрузка 9 МиБ перехвачена локальными ответами, не отправлена в Bunny.
- `tools/check-media-members-browser.mjs`: **28 проверок** интерфейсов зрителя и администратора, ручной выдачи/отзыва, создания коллекции, неизвестного зрителя; RU/EN/DE на 375, 390, 430, 1440 px. Ошибок JS и горизонтального переполнения не обнаружено. Скриншоты: `output/media-members-check/` (локальные fixtures, не входят в Git).
- В последнем прогоне новых интерфейсов PerformanceObserver не зарегистрировал Long Tasks на указанных ширинах. Heap Chrome примерно 1.6–4.5 МБ; это разовый локальный замер, не доказательство отсутствия утечек и не показатель production/Core Web Vitals.
- `tools/test-media-staging.mjs`: настоящий **локальный эмулятор D1 / Wrangler 4.158.0**, все три миграции, 11 прикладных таблиц, `quick_check=ok`, нет ошибок внешних ключей, повторное применение не дублирует миграции. Удалённых команд — 0.
- Cloudflare Pages Functions успешно собраны локально командой `wrangler pages functions build`. Маршруты проверены, главная остаётся статической. Проверены синтаксис изменённых JS/MJS и шаблоны секретов в отслеживаемых/неигнорируемых текстовых файлах; находок нет. Это не заменяет provider secret scanning.

## Не выполнено и не заявляется как готовое в production

- Настройка Pages bindings, Access applications, реальный IdP/OTP-вход, bootstrap первого admin.
- Удалённая миграция 0003: файл подготовлен, самостоятельно не применялся.
- Реальные TUS-загрузки, обработка/обложки/подписанное воспроизведение существующей библиотеки Bunny, отрицательные тесты прямого MP4/HLS/сегментов и просроченных URL на CDN. Проверить их можно только после настройки окружения и секретов владельцем.
- Настоящий Safari/iPhone, воспроизведение из России, мобильная сеть и длительное воспроизведение уроков. Chrome с мобильным viewport не заменяет эти испытания.
- Новый домен не подключался; платные ресурсы не создавались; MEDIA_PAID_ENABLED не включался; платежный шлюз не подключался. Ручные разрешения не создают фиктивные покупки.
