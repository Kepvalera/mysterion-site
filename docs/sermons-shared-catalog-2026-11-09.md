# Общая медиатека «Медиа» и «Проповеди»

Причина расхождения: sermons-page.js читал пустой статический sermons-data.js, а media.js использовал опубликованные записи D1. Теперь обе страницы читают существующий `/api/media/videos`. Статический файл сохранён в проекте, но не подключается к странице «Проповеди»; данных в нём нет.

Фильтры передают category=sermon/conference/school/testimony; «Все» не передаёт категорию. Поиск передаёт q, используется существующий серверный поиск по названиям и описаниям. Отдельного поля спикера в D1 нет: имя находится, когда оно записано в названии или описании. Отдельный поиск по несуществующему полю не заявляется. Изменения схемы/данных не требуются.

Отображаются обложка из защищённого API, название, описание, год, категория и вид доступа. Для отсутствующей обложки используется нейтральный текстовый фон. Пустая категория показывает «Видео скоро появятся» / «Videos coming soon». Ошибка сети отличается от пустого каталога и позволяет повторить запрос. Поиск отложен на 300 мс, устаревшие запросы отменяются. Список загружается порциями по 24 с кнопкой «Показать ещё».

Общий media-player.js обслуживает обе страницы: бесплатный просмотр через прежний GET videos/id/play, платный — прежний POST view/play/id. При отказе iframe не создаётся. JWT, роли, сроки/права доступа и MEDIA_PAID_ENABLED проверяются прежним сервером. Разрешены только ожидаемые YouTube/Bunny iframe и собственный R2 stream endpoint. При закрытии/завершении сессии плеер очищается; устаревший ответ не подменяет выбранный материал. В _headers страницы «Проповеди» добавлена такая же CSP, как у «Медиа».

Существующие композиция, фильтры, шапка, цвета и адаптивная сетка сохранены. Небольшой sermons.css добавляет стили описаний, кнопок и сообщений. Главная страница и её сборки, админка, библиотека Bunny, записи D1, роли, секреты и настройки оплаты не изменялись.

## Проверки

- 105 браузерных проверок Chrome через настоящий серверный handle и SQLite в памяти: 320/375/390/430/768/1440 px, RU/EN, все категории, пагинация, поиск, обложка, пустое состояние, network retry, #testimonies, скрытые/будущие материалы и одинаковый новый материал на обеих страницах. Проверены Bunny/YouTube, отказ платного просмотра и очистка плеера. Политика CSP применяется из _headers. Ошибок JavaScript и переполнения нет.
- 65 существующих браузерных проверок медиатеки/админки прошли после выделения общего плеера.
- 234 серверных теста авторизации, публикации и прав доступа прошли. Бэкенд в этой задаче не изменён.
- RU/EN, синтаксис и шаблонный поиск секретов проверены.

Локальные тесты используют только временную SQLite и тестовые материалы; внешние плееры перехвачены, реальных изменений Bunny/D1 нет. Настоящий Safari/iPhone и вход платного зрителя в production в этих тестах не проверяются. Скриншоты: output/sermons-catalog-check/sermons-390.png и sermons-1440.png.

Публикация — через GitHub/Cloudflare Pages. Дополнительных переменных, миграций, копирования видео или ручного добавления записей для этой задачи не требуется.
